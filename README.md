# ReValue

AI-powered waste-to-value platform for college cafeterias.

## Mission

Prevent avoidable food waste, identify recyclable materials,
estimate recoverable value, and connect surplus to appropriate
recycling or donation pathways.

## MVP

- Food demand prediction
- Waste image classification
- Rule-based material valuation
- Recycler and NGO matching
- Environmental impact dashboard

## Technology

- Frontend: React, TypeScript, Vite
- Backend: Python and AWS Lambda
- API: Amazon API Gateway
- Database: Amazon DynamoDB
- Image storage: Amazon S3
- AI: AWS-compatible vision model, subject to access verification
